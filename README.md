# Dj-Video-Game

The game will be either 2D or terminal-based. Players will interact with their own DJ (an algorithm). If the DJ likes a song name, it will approve it; if not, the player must find a new DJ. Songs that were rejected by previous DJs can be proposed to new DJs, and if approved, the previous and current DJs may “argue” over the player’s choices, creating a dynamic and engaging gameplay loop.

This project is currently in its early stages. As development progresses, its scope and features will expand.
